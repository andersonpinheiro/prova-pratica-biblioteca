# Sistema de Empréstimo da Biblioteca

Projeto desenvolvido em Java para demonstrar conceitos de Programação Orientada a Objetos, princípios SOLID e padrões de projeto.

## Tecnologias
- Java
- POO
- SOLID
- Design Patterns

## Padrões de Projeto

- **Adapter:** utilizado para integrar o serviço legado do acervo, centralizando a conversão dos dados.
- **State:** utilizado para controlar os estados e as transições do ciclo de vida dos empréstimos.

## Funcionalidades
- Consulta de exemplares do acervo.
- Geração de relatórios da coleção.
- Controle do ciclo de vida dos empréstimos.
- Validação das transições entre estados.
